What to bring

A few things that make the walkthrough go a lot smoother:

  • Blue painter's tape — flag problem spots right on the wall/floor/cabinet as you find them, so the builder can find them later too.
  • Tape measure — double-check room dimensions against the floor plan.
  • Phone or tablet, charged — for this checklist and its photos (a portable charger doesn't hurt).
  • Flashlight — attics, crawl spaces, closets, and under sinks are rarely well lit.
  • Outlet/GFCI tester — a cheap 3-light plug-in tester checks wiring and GFCI trip/reset in seconds.
  • Small level — checks doors, cabinets, and countertops for square.
  • Notepad and pen — a low-tech backup if your device dies.
  • Your builder's spec sheet/contract — to confirm included features actually made it into the house.
  • Comfortable clothes and shoes you don't mind getting a little dusty.

Import your floorplan

Turn a photo of your own floorplan into this checklist using any AI that can read images (Claude, ChatGPT, Gemini, etc).

Step 1 — copy this prompt and send it to an AI along with a photo of each floor's plan:

You are helping me build a home walkthrough checklist from floorplan images.

I will share one or more floorplan images, one per floor level. For each image:
1. Identify every distinct labeled room or space (bedrooms, bathrooms, kitchen, closets, storage, garage, patio, etc).
2. Note each room's dimensions if they're labeled on the plan (e.g. 12' x 10'). Use null if not labeled.
3. For each room, write a short, practical checklist of 3-8 items a homeowner should verify during a new-construction walkthrough for that specific room type (outlets, fixtures, doors/windows, flooring, plumbing, appliances, ventilation — whatever applies to that room).

Output ONLY valid JSON, no markdown formatting, no code fences, no commentary before or after — just the JSON object, in exactly this structure:

{
  "floors": [
    {
      "key": "floor1",
      "label": "1st Floor",
      "rooms": [
        {
          "id": "kitchen",
          "name": "Kitchen",
          "dims": "10' x 12'",
          "items": [
            "Cabinets and drawers open smoothly and align",
            "Countertop seams are tight, no chips"
          ]
        }
      ]
    }
  ]
}

Rules:
- "key" for each floor is a short unique slug, e.g. floor1, floor2, basement, garage.
- "id" for each room is a short unique slug (lowercase, no spaces or punctuation) — it must be unique across the ENTIRE house, not just within one floor.
- "dims" is a string like 10' x 12', or null if not shown on the plan.
- "items" is an array of plain strings, each one checklist item.
- Include every floor I show you as its own entry in "floors", in the order I share the images.
- Do not include any text outside the JSON object.
